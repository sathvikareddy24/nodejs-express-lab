## Objective
To create a basic Node.js HTTP server and an Express server with multiple routes.

## Technologies Used
- Node.js
- Express.js
- JavaScript

## Installation and Execution

1. Install Node.js.
2. Open Command Prompt in the project folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the Express server:

   ```bash
   node server.js
   ```

5. Open `http://localhost:3000` in your browser.

## API Endpoints

| Method | Endpoint | Description | Expected Status |
|---|---|---|---|
| GET | `/` | Displays the welcome message | 200 |
| GET | `/about` | Displays name and section as JSON | 200 |
| GET | `/time` | Displays the current date and time | 200 |
| GET | `/contact` | Displays a not-found message | 404 |
